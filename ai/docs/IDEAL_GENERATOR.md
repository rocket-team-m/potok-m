# Идеальный генератор обучающих данных: привилегированный учитель и сенсорный студент

SPDX-License-Identifier: GPL-3.0-or-later

Статус: спецификация контракта данных и процедуры, без кода. Канонический исходник —
дерево `ai/`; корневая копия `src/potok_ai/` устарела (нет v3 `g_accel`,
`src/potok_ai/data.py:38-41` против `ai/src/potok_ai/data.py:36-38,415-456`).

## 0. Принцип

Один и тот же эпизод даёт три несмешиваемые роли: **привилегированное состояние**
только учителю, **сенсорная история** студенту, **ответ** только функции потерь.
Граница проводится до любой модели и проверяется на каждом вызове. Генератор
должен уметь доказать, что он сгенерировал именно то, что заявлено, — гейты
генератора предшествуют гейтам модели (`ai/docs/IDEAL_DATA_RESEARCH.md:253-269`,
`.bulba/night/WORLD05.md:176-178`).

## 1. Поля v3: что идёт в `z_priv`, что в метки, что в student

Источник — два файла на эпизод: `validation.bin` v3 и потиковый сайдкар
`POTOKTRJ` v3 (`sim/core/src/trajectory.rs:25-30,85-114`;
`sim/README.md:293-330`). Заголовок сайдкара — 64 байта, шаг 26 f32; версия и
шаг — авторитет, любое расхождение — LOUD (`ai/src/potok_ai/privileged_teacher.py:105-160`).

| Роль | Поля | Код |
|---|---|---|
| `z_priv` (22 → 8 чисел, RMA-бутылочное горлышко) | слоты **0..21** сайдкара: `pos[3], vel[3], quat[4], omega[3], mass, wind[3], gust_start_s, gust_amplitude, shear_altitude_m, shear_delta, shear_thickness_m` | `trajectory.rs:85-114`, `privileged_teacher.py:51-70,169-212,255-257` |
| Метки | слоты **22..25**: `g_theta_roll/pitch` (22–23, ***только*** диагностика в радианах) и `g_accel_y/x` (24–25, м/с²). Авторитетная команда шва — `[g_accel_y, −g_accel_x]` в порядке `[roll, pitch]`; совпадает с колонками 4–5 v3 | `trajectory.rs:25-28,109-113`, `ai/src/potok_ai/data_v3.py:6-14,41-60`, `sim/README.md:318-323` |
| Student | окно **50 кадров × 14 признаков** (1 с при 50 Гц) + **6 conditioning** (`mass, area, cd0, static_margin_cal, thrust_peak_n, gyro_noise`) = 20 входов/тик | `ai/src/potok_ai/data.py:58-59,187-198,415-456`, `privileged_teacher.py:72`, `SPEC_SMART.md:22-24,34` |

Нормализация привилегированных полей считается **только по train-сайдкару** и
кластер хранится вместе с учителем; удержанные truth-данные не участвуют
(`privileged_teacher.py:215-246`). Энкодер инициализируется закрытым генератором
из именованного подпотока, глобальный RNG не читается и не сдвигается
(`privileged_teacher.py:169-199,163-166`). Порядок полей брать из
`TRUTH_V3_TICK_NAMES` / `TRUTH_SLOT_NAMES`, а не из модульного докстринга
`privileged_teacher.py:6-8` — там порядок устарел.

Текущий разрыв: `loopwm.py:1-10` и `train_loopwm.py:91-107` кормят учителя только
сенсорным окном, истина идёт лишь в loss; `PrivilegedFeatureBuilder` создан, но в
тренер не подключён. Спецификация требует подключить `z_priv` во forward учителя
и оставить метки вне forward (`SPEC_SMART.md:26-32`, `.bulba/night/WORLD03.md:13-34`).

## 2. Кривые сложности и темп

Базовый скелет — кумулятивные стадии `curriculum.py:20-29,44-59`; назначение
стадии по `scenario_id % 4` — явно помеченный плейсхолдер и должен быть заменён
на сигнатуру сценария / значения DR-knobs, а не на номер id.

| Стадия | Критерий входа | Назначение |
|---|---|---|
| S0 Nominal | `gust_u == 0 ∧ shear_u == 0` | нулевая команда, проверка отображения команды; якорь спокойного replay |
| S1 Gust | `gust_u > 0 ∧ shear_u == 0` | основной 1-cos DR-режим: амплитуда, момент, градиент, оба знака |
| S2 Shear / mean wind | `gust_u == 0 ∧ shear_u > 0` | `v10_u`, `shear_u`, `shear_alt_u` — изолированные проходы |
| S3 Compound | `gust_u > 0 ∧ shear_u > 0` | связанная тяжесть `c`; только оценка, не атрибуция |
| S4 Turbulence | `sigma_factor > 0` | согласованные по `TI` и `L` AR(1)/Dryden и von Kármán рунги |
| S5 Sensor lag / faults | `lag_scale > 1`, `latency_steps`, шумы | обучающие ячейки с `lag_scale` 1.0–1.4; 1.5–2.0 остаются OOD |
| S6 Adversary (bounded) | генератор, не ячейка | агент ветра внутри активной стадии; потолок win-rate ≈30 %, `V_max`, σ по стадии |

Стадии кумулятивны: ранее пройденный материал остаётся в миксе
(`curriculum.py:44-49`). Темп: масса спокойного replay **15 %**, остальные 85 % ~
`U(0, c_stage)`; `c_stage` растёт линейно на первой половине стадии; адаптивный
вариант поднимает `c` только при высоком текущем успехе, и фактический `c`
пишется в манифест (`.bulba/night/WORLD05.md:118-124`). Изолированные
однокнопочные проходы живы на всех стадиях от S1; связанная тяжесть служит только
для оценки (`.bulba/night/IDEAL_DATA_RESEARCH.md:189-195`). Модель выбирается
leave-one-scenario-out по ячейкам 0–15; стадия не гарантирует монотонного выигрыша.

## 3. Рандомизация возмущений

* **1-cos порыв.** Форма `g = ½·A·(1−cos 2πu)`, `u = (t−t0)/d`,
  `t0 ∈ [0.08, 0.63]·T` (`sim/core/src/wind.rs:52-75`). Амплитуда берётся из
  `gust_amplitude_range = [5,20]` м/с (`sim/core/src/config.rs:91-93,116-118`).
  Длительность и знак направления уже разыгрываются на эпизод:
  `duration_factor_range = [0.5,1.5]` и `direction_sign ∈ {−1,+1}`
  (`config.rs:370-371,406-407,483-488,500`). Обязательно логгировать градиент
  `≈ v_ref · gust_duration_s` и покрывать оба знака; гейт: реализованная форма
  равна `½A(1−cos 2πu)` на `[0,1]`. `g_roll/g_pitch` никогда не подменять
  командой (`data_v3.py:6-11`).
* **Турбулентность.** Три AR(1)-фильтра `x_{k+1}=a x_k+σ√(1−a²)w_k`,
  `a=exp(−dt·v_ref/L)`, масштабы `[1,0.8,0.45]`
  (`wind.rs:77-100`). На эпизод разыгрываются `sigma_factor_range=[0.5,1.5]` и
  `scale_factor_range=[2/3,1.5]`, удержанные — непересекающиеся
  `[2,2.5]` и `[0.4,0.6]` (`config.rs:384-386,400-417,479-482,701-715`).
  Гейт: дисперсия `(TI·U)²`, наклон инерционного участка ≈ −5/3, воспроизводимость
  по seed. Von Kármán — OOD/эталон оценщика, **не** обещание робастности; LES не
  финансируется как фикс (`IDEAL_DATA_RESEARCH.md:144-163,290-295`).
* **Задержка датчика.** Обучающий `lag_scale ∈ [1.0,1.4]`, удержанные ячейки
  16–19 несут `1.5/1.8/1.6/2.0`; `Sensor::new` умножает оба множителя
  (`config.rs:378,397-399,459-463,501,716-725`; `scenario.rs:52-53,210-243`;
  `sensor.rs:222-233`). Плюс `latency_steps`, квантование, насыщения, шум/сдвиг
  гиро и акселя, spike (`config.rs:158-205`). Пересечение обучающего и
  удержанного диапазонов — LOUD-отказ (`config.rs:719-725`).
* Все DRAW-потоки независимые поименованные подпотоки `episode_seed(seed, index ^ tag)`
  (`config.rs:446-449`, метки `DR_LAG/DR_TURB_*/DR_GUST_*` в `config.rs:370-371`);
  замена одного knob'а не должна сдвигать остальные — это пинется
  `sim/core/tests/curriculum_tests.rs:1-14,44-90`.

## 4. Дисциплина удержанных

1. Обучение и все выборы — только ячейки **0–15**; **16–19** — запечатанный
   финальный отчёт: никакого тюнинга, early stopping, калибровки уверенности или
   выбора порога (`scenario.rs:210-243`; `SPEC_SMART.md:60-61`).
2. DAgger отклоняет eval-эпизод до вызова роллаута или учителя
   (`ai/src/potok_ai/dagger.py:40,101-104,185-190`); внутренний fit/held-out —
   непересекающееся подмножество обучающих ячеек, метки только от эксперта
   (`dagger.py:107-125,159-233`).
3. Аугментация не должна касаться удержанных: они побитово тождественны источнику
   (`ai/tests/test_augment_gate_hard.py:79-106`).
4. Раздельный seed оценки, ≥3 seed на руку, ≥5 seed × 10 эпизодов на ячейку;
   эффект сравнивается с разбросом собственных seed контроля. В каждой цифре
   печатать окно оценки и id сценариев (`.bulba/night/WORLD05.md:142-150`).
5. Композиционные OOD-ячейки и однокнопочная OOD-лестница отчитываются
   отдельно; усреднять их в один заголовок запрещено.

## 5. Seed и provenance

Один верхний seed; все стохастические потоки — именованные дети:
`child_seed` = sha256("seed:name") (`privileged_teacher.py:163-166`),
`f"{seed}:{epoch}"` (`curriculum.py:54-59`), `f"{seed}:dagger:..."`
(`dagger.py:24-26,203`), `episode_seed` с тегами (`config.rs:446-449`).
Глобальный RNG не читается и не перезасевается после consumption; `split`
фиксируется сценарием, а не seed. `torch.manual_seed` — один раз до создания
параметров (`.bulba/night/WORLD03.md:319-338`).

Каждый датасет несёт `manifest.json`: `config_hash` (sha256 канонического TOML),
`seed`, `split`, отсортированные `scenario_ids`, счётчики, имена полей, bounds и
sha256 файлов — без меток времени и PID (`sim/core/src/manifest.rs:1-6,76-96,98-131`).
Рядом — `manifest.provenance.json`: `manifest_hash`, `code_hash` (git HEAD),
`protocol_schema_hash`, `measurement_hashes`, `golden_episode_hash`
(`manifest.rs:168-190,344-375,413-493`). Каждая строка DAgger несёт
`Provenance` с sample_id/seed/round/rollout/step/episode/scenario/split/expert
(`dagger.py:63-77,211-233`). Чекпоинт учителя дополнительно хранит seed, стадию,
SHA-256 данных и сайдкара, config hash; resume при расхождении конфигурации —
отказ. Никаких внешних заявлений о происхождении, кроме GPL и перечисленных hash'ей.

## 6. Что измерять

Первичные метрики — из реально пролететной траектории POTOKTRJ v3 (не суррогат)
за все 30 с, по эпизоду и в разрезе seed (`ab_report.md:9-15,151-158`):

* `g_lat = 1 − lateral_rms_assisted / lateral_rms_zero` — относительное снижение
  бокового RMS (`trajectory.rs:263-273`). Ориентиры: oracle 1528.366 → 1035.228 м,
  `g_lat ≈ 32.3 %`; экспортированные студенты ≈ **1.7 %** (`ab_report.md:23-43`).
* `g_apg = apogee_assisted / apogee_zero − 1` — относительный прирост апогея
  (`trajectory.rs:247-261`). Ориентиры: oracle 1734.977 → 3971.197 м,
  `g_apg ≈ +129 %`; студенты ≈ +125 м ≈ +7 % (`ab_report.md:23-43`).

Обязательны: абсолютные значения в метрах, `n`, три seed и их разброс, то же
окно/те же ячейки для всех рук, нулевая команда как baseline и привилегированный
oracle как положительный контроль, честный геометрический/H∞-контроль при
равных условиях (`.bulba/night/WORLD05.md:75-76,149`). Порог отличия от шума
сайдкара: дельта < 0.001 м — численная ничья (`ab_report.md:15`). Вторичные
гейты: held-out/train RMSE ≤ 1.25 (`SPEC_SMART.md:63-67`), расхождение
студент–учитель ≤ 1.5 шума, decodability ветра из сенсорной истории, конечность
команд и предел ±10 м/с² на шве. Отсутствующий seed не подменяется
stand-in'ом (`ab_report.md:17-19`).

## 7. Что запрещено

1. **Контаминация оценки:** ячейки 16–19 в обучении, DAgger-роллаутах, подборе
   гиперпараметров, early stopping или калибровке; выбор чекпоинта по ним —
   oracle-результат и аннулируется (`dagger.py:101-104,185-190`).
2. **Тихие подмены (fallback):** нулевая подстановка вместо неточного truth
   (`privileged_teacher.py:24-27`), превращение `g_theta` в команду для v1/v2
   (`data_v3.py:41-48`), нулевой target в `SmartWindowDataset:444-449`,
   подмена версии/шага, пропуск гейта генератора. Отказ обязан называть причину
   и способ исправления.
3. **Непромаркированная утечка привилегий:** слоты 0..21 или метки 22..25 во
   forward студента и в потребителях манифеста на борту; `assert_student_clean`
   (`privileged_teacher.py:263-270`) и проверка сигнатур обязательны. Любой
   привилегированный канал идёт с явной меткой и COUNTED-счётчиком
   (`privileged_teacher.py:14-17`, `.bulba/night/WORLD03.md:218-220`); сырые
   массивы без provenance в датасет не идут.
4. **Подмена программы:** заявление «учитель привилегирован» при loss-only truth
   (`loopwm.py:6-10`), стадия `sensor_fault` без обучающих ячеек с lag > 1,
   сравнение arm'ов на разных окнах/seed/конфигурациях.
5. **Ложная робастность:** вывод об устойчивости по одному seed, по внутренней
   области без OOD-лестницы или против fixed-gain PID, выданного за строгий baseline
   (`.bulba/night/WORLD05.md:88-98,172-188`).
