# Сравнение: LoopWM (учитель) и LRS-TCN (студент)

Статус: черновик, 22 ноября 2026. LRS-TCN ещё не реализован, оценки аналитические.

| Параметр | LoopWM, привилегированный учитель | LRS-TCN, бортовой студент |
|---|---|---|
| Место | обучение, офлайн | Raspberry Pi, 50 Гц |
| Единица вычисления | окно 50 кадров | один кадр за тик |
| Архитектура | параметрически общий Transformer-блок | 2 stateful низкоранговых TCN-блока |
| Итерации | итеративное уточнение латента, adaptive depth, cap 6 | 1–3 loop с AttnRes, жёсткий cap |
| Признаки | 14 входных + 6 conditioning | 14 входных + 6 conditioning |
| Привилегированная информация | истинный ветер и полное состояние в обучении | недоступна |
| Цель обучения | латент на 3/6/10 кадров вперёд + поправка | повторить выход учителя |
| Состояние | латент внутри цикла уточнения | 2 × 64 чисел между кадрами |
| Рецептивное поле | всё окно через attention | состояние переносится во времени |
| Рекуррентные матрицы | нет | низкоранговые 64×16 вместо 64×64 |
| Мульти-скорость | нет | fast каждый кадр, slow раз в 4 |
| MAC (оценка) | несколько млн за окно | около 50 тыс. за кадр |
| Задержка на Pi | не запускается | 0,1–0,2 мс (оценка) |
| Память | не критична | около 12 КБ (оценка) |
| Веса | не связаны с бортом | тернарные факторы и рекуррентные матрицы |
| Отказ | не влияет на полёт | сброс состояния на смене фазы |
| Роль | источник целевых представлений и поправок | исполнитель на борту |

Связь между ними: LoopWM смотрит будущее с привилегированной информацией и
выдаёт цели; студент учится воспроизводить эти цели по доступным датчикам.
Скорость и простота нужны только студенту, поэтому учитель может быть сколь
угодно глубоким, если его выход можно дистиллировать.

До реализации LRS-TCN числа в графе студента — аналитическая оценка. Измеряются
фактические MAC, p50/p99 на Raspberry Pi и RMSE на удержанных сценариях.
