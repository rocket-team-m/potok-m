# Идеальный контур обучения: критерии приёмки

Статус: рабочая спецификация.

## Принцип

Точность даёт не размер модели, а цепочка: физика → датчики → протокол →
обучение → удержанная проверка. Каждое звено имеет числовой gate.

## 1. Физика

- Карточка коэффициентов $C_D$, $C_m$, $C_{m\delta}$ на сетке $(M, \alpha)$.
- Интерполяция бикубическая, экстраполяция запрещена: выход за сетку — LOUD.
- Тяга по паспортному профилю, масса и инерция меняются на активном участке.
- RK4, шаг 0,002 с, кватернион нормируется каждый шаг.
- Сходимость по сетке CFD: три уровня, разница коэффициентов <2%.

## 2. Датчики

- Шумы и смещения из Allan variance, не из даташита.
- Квантование, частоты дискретизации, задержки, насыщение и выбросы.
- Вихревой выпрямленный шум и случайное перетекание гравитации между осями.
- Кадр совпадает с `protocol/uart.yaml` (14 признаков + 6 Conditioning).
- truth: истинный ветер, момент порыва, амплитуда, состояние ракеты.

## 3. Сценарии

- 20 детерминированных ячеек ветра/порывов; 16 train, 4 held-out.
- Split по сценарию, не по типу ракеты.
- Один seed на эпизод, без глобального ГПСЧ.

## 4. Обучение

- Loss = normed residual к эталону + 0,05 JEPA + 0,02 MTP.
- Curriculum: спокойный ветер → порывы → сдвиговый слой → сбой датчика.
- Три сида на конфигурацию; win должен превысить разброс контроля.
- Gate: `rmse_held_out / rmse_train <= 1,25`.

## 5. Калибровка

- Confidence калибруется на удержанных сценариях.
- ECE <= 0,05; порог adaptive compute берётся из калибровки, не из 0,5.
- Один отчёт: RMSE, MAE, max error, ECE, params, MAC, bytes, p99.

## 6. Стык

- Симулятор пишет validation v2.
- Движок читает v2 и печатает metrics.json.
- Edge сверяет golden-байты с Python с допуском 1e-5.
