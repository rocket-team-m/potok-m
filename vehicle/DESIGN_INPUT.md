# Что нужно для расчёта конструкции

Статус: запрос входных данных. Файлы >2 МБ в git не кладём — локальный путь или Releases.

## Минимум, чтобы начать

1. **Геометрия STEP** — полная сборка и отдельно носовой обтекатель, корпус,
   перья, двигательные шахты. Формат AP214/AP203, единицы — мм.
2. **STL (binary, мм)** — та же геометрия для CFD-сетки.
3. **Массовые характеристики из SolidWorks**: масса каждого узла, ЦМ сборки,
   тензор инерции, точки крепления ступеней.
4. **Паспорта двигателей** — тяга по времени (или PDF), масса топлива, время
   горения, полный импульс, пиковая тяга.
5. **Материалы** — название, плотность, толщина стенки, для композита — схема
   укладки; для перьев — материал и толщина.

## Для «идеального» расчёта

6. Ограничения: макс. диаметр и длина, минимальная толщина стенки,
   технология (печать/фрезеровка/композит), стоимость.
7. Диапазон центровки: допустимое положение ЦМ и желаемый запас устойчивости.
8. Аэродинамика, если уже есть: OpenRocket-файл, Ansys-проекты, таблицы
   $C_D(\alpha,M)$, $C_m(\alpha,M)$, данные продувок.
9. Приоритет оптимизации: устойчивость в порывах / апогей / масса /
   технологичность — что важнее.
10. Эскиз компоновки: где БК, батарея, парашюты, датчики, жгуты.

## Что я сделаю после получения

| Шаг | Результат |
|---|---|
| Проверка STEP/STL,проверка масштаба | таблица размеров и масс, находим расхождения с ТТХ |
| Быстрая модель | сетка вариантов: $C_D$, $C_m$, $C_{m\delta}$, запас, апогей |
| CFD на лучших | уточнённая карточка по $M$ и $\alpha$ |
| Оптимизация | Парето-таблица: масса ↔ устойчивость ↔ апогей |
| Отчёт | что изменить в конструкции и почему, с числами |

Расчёт не заменяет продувку и лётный запуск: он сужает набор кандидатов.
