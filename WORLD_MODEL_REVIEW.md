# Обзор world model для учителя «Поток-М»

Статус: черновик, 22 ноября 2026.

| Работа | Идея | Relevant? |
|---|---|---|
| Looped World Models, arXiv:2606.18208 | общий блок, итеративное уточнение латента, adaptive depth | взята как основа учителя |
| Variable-Length Latent World Models, arXiv:2606.21775 | предсказание будущего на переменном горизонте без рекурсивного роллаута | близко к нашим целям 3/6/10 кадров |
| Fast-JEPA, arXiv:2611.25927 | прямое предсказание исхода полного кандидата | взята для one-shot цели студента |
| Contrastive World Models, arXiv:2609.22175 | латентная динамика без реконструкции | совпадает с нашим JEPA, реконструкции нет |
| AdaJEPA, arXiv:2606.32026 | тест-время адаптация одним градиентом в MPC | не берём: в полёте модель заморожена |
| JEPA-TTT, arXiv:2610.00722 | постоянная адаптация предиктора при сдвиге динамики | только на земле между пусками |
| LeFlow, arXiv:2608.24855 | амортизированное планирование в латенте | не берём: мы не ищем последовательность действий |
| V-JEPA 2, arXiv:2506.09985 | BIG видеомодели для предсказания и планирования | веса не нужны, масштаб не наш |

Вывод: для нашей задачи нет работы, которую можно было бы просто поставить
вместо LoopWM и получить лучший результат. Ближайшие идеи уже включены:
итеративное уточнение, multi-horizon цели, латентное предсказание без
реконструкции. Недостаток качества учителя на реальных данных, вероятно, не в
архитектуре, а в диагностируемых параметрах: exit threshold, масштаб latent loss
и качество эталонных целей.
