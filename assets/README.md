# Аудио-демо для бортового динамика

- `BadApple.mid` — MIDI-транскрипция Bad Apple!! из публичного репозитория
  `Handhule90/badapple-midi`. Оригинальная музыка: ZUN, Touhou Project.
- `make_bad_apple_from_midi.py` — рендер MIDI в звук пьезоизлучателя:
  прямоугольная волна с 28% duty cycle, треугольная для баса, шум для ударных, 48 кГц.
- `badapple_buzzer.opus` — полная версия 3:38, все 13 дорожек MIDI. У каждой дорожки своя таблица нот, поэтому note-off одной не обрывает другую. Ударные — шумовые всплески, бас — треугольная волна, мелодии — прямоугольная. Есть `.mp3` для плееров, которые не открывают Opus.

MIDI — community-транскрипция, не оригинальный аудиофайл. Использование
внутри команды и на защите без коммерческого распространения.
