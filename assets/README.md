# Аудио-демо для бортового динамика

- `BadApple.mid` — MIDI-транскрипция Bad Apple!! изпубличного репозитория
  `Handhule90/badapple-midi`. Оригинальная музыка: ZUN, Touhou Project.
- `make_bad_apple_from_midi.py` — рендер MIDI в звук пьезоизлучателя:
  square wave, 28% duty cycle, 48 кГц.
- `badapple_buzzer.opus` — 24 с, 98 КБ, демо после посадки.

MIDI — community-транскрипция, не оригинальный аудиофайл. Использование
внутри команды и на защите без коммерческого распространения.
