`potok-m-edge` — Raspberry Pi 4 B (2 ГБ). Он получает окно телеметрии по UART,
держит состояние студента между вызовами и отдаёт две ограниченные поправки.
В репозитории нет модельного бинарника: он приходит из `potok-m-ai` при
разворачивании; здесь лежат только детерминированные тестовые фикстуры.

## Форматы моделей

| Формат | Magic | Заголовок | Вход | Записи |
| --- | --- | ---: | --- | --- |
| v2 windowed teacher | `POTOKM1\0` | 56 Б | окно 8 признаков × 50 кадров | `5·n_blocks + 6` |
| v2 stateful student | `POTOKM1\0`, `model_kind = 2` | 56 Б | 10 или 20 входов | — |
| v3 fast model | `POTOKM3\0` | 64 Б | 20 входов | `5·n_blocks + 10` |

V3 несёт `model_kind = 2`, `target_version = 3`, флаги ровно 1, 1–3 цикла и
обязательный набор записей без дубликатов и хвостовых байт. Замыкающий хвост
из 32 байт — SHA-256 по всем предыдущим байтам; несовпадение — жёсткая ошибка
без частичной загрузки. Разложение factors: `W[out,in] = U·alpha_u·s·V·alpha_v`.
Ритер `V3Model` проверяет тип ternary-кодов, размеры с проверкой переполнения и
отвергает любые отклонения типизированной `V3Error`.

## Калибровка

Rust-читатель принимает `calibration.json` (`temperature`, `isotonic`) и
`conformal.json` (`split-conformal`) и проверяет весь payload: конечные числа,
положительную температуру и `tol`, `alpha` в (0,1), положительное `n`,
покрытие в [0,1], монотонные пары границ, отсутствие дублей ключей.
`apply_logit(z)` даёт `sigmoid(z/T)` или ступеньку по `p = sigmoid(z)`;
для conformal без карты — точный индикатор `p >= 1/(1+q_hat)`. Порог
data-derived, константы по умолчанию нет.

В dispatch по умолчанию используется `DEFAULT_CONFIDENCE_THRESHOLD = 0,7` —
это конфигурация диспетчера, а не порог из калибровки: production-путь пока не
вызывает `apply_logit`.

## Цикл и измерение

Цель — <10 мс p99 полного цикла при 50 Гц. Стоимость провода: полный профиль
56+14 Б, облегчённый 42+16 Б. В бенчмарке `bench_v3` четыре таймера делят
model (окно), overhead (encode/decode и ведение окна) и total; `--check`
прогоняет конвейер дважды и сверяет контрольную сумму.

Две конвенции процентилей сосуществуют: nearest-rank в бинарниках bench и
линейная интерполяция `q·(n−1)` в `lowlat_perf_hard_tests.rs`. Гейт проверяет
структуру и зафиксированную сумму, а не микросекундный порог. На этом x86-хосте
release-прогон даёт p50/p99 ≈170/236 мкс полного цикла, модель ≈169/235 мкс,
decode ≈0,26/0,31 мкс, encode ≈0,21/0,28 мкс — это справочные числа, не
доказательство для Raspberry Pi. Debug-интеграционный тест даёт ≈11,2 мс при
лимите 10 мс; release-профиль зелёный.

## Интеграционные разрывы

- `Runtime::load` dispatch'ит только `POTOKM1\0` и legacy `POTM`; ветки
  `POTOKM3\0` нет, хотя `V3Model` и `V3Dispatch` готовы и покрыты тестами.
- Ни один production-вызов не потребляет `Calibration`.
- Writer v3 в `potok-m-ai` отсутствует: формат модели зафиксирован ридером.
- p99 на Pi не измерен, NEON проверен только компиляцией.
