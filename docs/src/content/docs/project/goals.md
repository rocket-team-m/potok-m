«Поток-М» — двухступенчатая ракета на твёрдотопливных двигателях с
классической системой спасения и ИИ-ассистентом стабилизации в режиме
наблюдателя. Документация и ADR живут здесь, код — в канонических
репозиториях; подробная карта — в [архитектуре](/potok-m/docs/project/architecture/).

## Канонические репозитории

| Репозиторий | Что лежит |
| --- | --- |
| [potok-m](https://github.com/rocket-team-m/potok-m) | этот сайт, ADR, общие артефакты |
| [potok-m-ai](https://github.com/rocket-team-m/potok-m-ai) | обучение модели, LRS-TCN/RMS-TCN, LoopWM, экспорт |
| [potok-m-sim](https://github.com/rocket-team-m/potok-m-sim) | 6-DoF симулятор, рандомизация, validation v3 |
| [potok-m-protocol](https://github.com/rocket-team-m/potok-m-protocol) | UART-протокол, генератор биндингов, C-эталон |
| [potok-m-firmware](https://github.com/rocket-team-m/potok-m-firmware) | прошивка STM32H743 на Embassy, SIL и тайминг |
| [potok-m-edge](https://github.com/rocket-team-m/potok-m-edge) | инференс на Raspberry Pi, калибровка, dispatch |
| [potok-m-3d](https://github.com/rocket-team-m/potok-m-3d) | текстовые CAD-входы и обмен геометрией |
| RocketCraft / `potok-m-workbench` | приватный воркбенч: CAD → mesh → CFD/FEA → аэрокарточка → траектория → отчёт |

Изменения кода вносятся в канонический репозиторий. Аэрокарточку, которую
потребляет симулятор, производит RocketCraft.

## Тактико-технические характеристики

| Параметр | Значение |
| --- | --- |
| Стартовая масса | 10,4–11,4 кг (OpenRocket Simulation 9) |
| Проектная высота | порядка 3 км |
| Максимальная скорость | M=0,5–0,6 по ТТХ; OpenRocket Simulation 9 даёт 274 м/с (M=0,82), симулятор — 278 м/с. Противоречие открыто, коэффициенты под число не подгонялись |
| Внутренний диаметр корпуса | 102 мм |
| Статический запас устойчивости | 0,0765 м, около 0,75 калибра при 102 мм |
| Двигатели | РДК-2000: импульс 2,2–2,4 кН·с, средняя тяга 390–400 Н, работа 5–6 с, топливо 1,88 кг; РДК-1000: 1,0–1,2 кН·с, 260–270 Н, 3–3,5 с, 1,0 кг; минимум по паспортам — 3,2 кН·с |
| Бортовая платформа | STM32H743, контур управления 500 Гц; Raspberry Pi 4 B (2 ГБ) — советчик по UART 50 Гц |

Величины выше — расчётные и паспортные. Полётных измерений нет, поэтому
характеристики не являются подтверждёнными лётными данными.

## Цели сезона

- Устойчивый полёт с работающей системой спасения.
- Предсказуемая точка посадки и точность выведения.
- Воспроизводимая цепочка «аэрокарточка → симулятор → обучение → борт» с
  честными гейтами на каждом звене.
- ИИ-ассистент, проверенный на симуляторе и стенде. V3 closed-loop A/B в
  симуляции пройден; до реальных пусков ассистент остаётся наблюдателем.
