«Поток-М» — двухступенчатая ракета на твёрдотопливных двигателях.

## Тактико-технические характеристики

| Параметр | Значение |
| --- | --- |
| Стартовая масса | около 13 кг |
| Проектная высота | порядка 3 км |
| Максимальная скорость | около 240 м/с |
| Статический запас устойчивости | около 0,957 калибра |
| Калибр | 102 мм |
| Бортовая платформа | STM32 |

## Цели сезона

- Устойчивый полёт с работающей системой спасения.
- Точность выведения и предсказуемая точка посадки.
- ИИ-ассистент стабилизации, проверенный на симуляторе, стенде и пусках.

:::caution
Раздел в работе. Числа сверяются с техзапиской: в ней ещё старая редакция
(12,365 кг, 250 м/с, 1,96 калибра).
:::
