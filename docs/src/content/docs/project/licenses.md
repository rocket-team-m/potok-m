## Собственный код

Весь собственный код Potok-M и RocketCraft распространяется по
`GPL-3.0-or-later`. Это зафиксировано в корневом `LICENSE`, в SPDX-заголовках
исходников и в полях `license` манифестов. CI-гейт `license-gate` в
`.github/workflows/guard.yml` проверяет три условия: `LICENSE` содержит текст
GNU GPL версии 3, `LICENSE-COMMERCIAL.md` присутствует и называет
`GPL-3.0-or-later`, ни один SPDX-заголовок или манифест не объявляет другую
лицензию для собственного кода. Ошибка — жёсткая, с именем файла и строки.

Внутреннее использование без распространения не обязывает открывать код. Если
модификация распространяется под GPL, её исходники должны быть доступны
получателю.

## Коммерческая лицензия

Для проприетарного использования предусмотрена отдельная лицензия: условия в
`LICENSE-COMMERCIAL.md` каждого репозитория. Выбор простой: распространяете
модификацию под GPL — открываете код; нужна проприетарная интеграция —
заключается коммерческое соглашение.Dual-license для собственных файлов
реально работает только при подписанном соглашении контрибьютора (CLA); это
требуется в спецификации RocketCraft.

## Сторонние компоненты

Сторонний код не перелицензируется. Его лицензии и уведомления поставляются
вместе с артефактами в `NOTICE` и `THIRD-PARTY-LICENSES`.

| Компонент | Лицензия |
| --- | --- |
| solidcore | `Apache-2.0` с сохранённым NOTICE |
| части, производные от SolidCraft | `MIT OR Apache-2.0` с атрибуцией |
| Inter | `OFL-1.1` |
| OpenTUI Mono | собственная лицензия шрифта |

 Шрифтовые бинарники в репозиторий RocketCraft не включаются: GPUI запрашивает
семейства по имени и использует системный стек шрифтов. Тексты лицензий
остаются в `crates/ui/fonts/NOTICE.md`. Ораклы (OpenRocket, лицензированные
Fluent-фикстуры) работают только в dev/CI и не попадают в поставляемый
артефакт; в поставку входят golden-фикстуры.

AGPL не используется: RocketCraft — десктопное приложение без сетевого
триггера.

Собственный код — `GPL-3.0-or-later`, подробности — в
[целях проекта](/potok-m/docs/project/goals/).
