Раздел в работе. Имена не публикуются: роли важнее, состав меняется.

## Роли

| Роль | Зона ответственности |
| --- | --- |
| Командир | сроки, приоритеты, приёмка задач, связь с оргами |
| Борт | электроника, авионика, прошивка, спасение и поиск |
| ИИ | модель, обучение, симулятор, обработка телеметрии |
| Форма | чертежи, CAD, аэродинамика |
| Документация | сайт, решения, отчёты |

## Правило

Задача без ответственного и срока не считается задачей. Передача задачи
фиксируется в Issues, а не в личных сообщениях.
