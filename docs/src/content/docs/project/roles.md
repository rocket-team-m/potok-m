Имена не публикуются: роли важнее, состав меняется.

| Роль | Зона ответственности | Канонический репозиторий |
| --- | --- | --- |
| Командир | сроки, приоритеты, приёмка задач, связь с органами | `potok-m` |
| Борт | электроника, авионика, прошивка, спасение и поиск | `potok-m-firmware`, `potok-m-protocol` |
| ИИ | модель, обучение, телеметрия, симулятор и данные | `potok-m-ai`, `potok-m-sim`, `potok-m-edge` |
| Форма | чертежи, CAD, аэродинамика, аэрокарточка | `potok-m-3d`, RocketCraft |
| Документация | сайт, ADR, спецификации, отчёты | `potok-m` |

## Правило передачи

Задача без ответственного и срока не считается задачей. Передача фиксируется
в Issues, а не в личных сообщениях. Одна задача — одна ветка; в `main` — через
pull request. Код и изменения вносятся в канонический репозиторий: карта — в
[архитектуре](/potok-m/docs/project/architecture/).

Решения, меняющие интерфейс между репозиториями, фиксируются ADR. Примеры:
владелец аэрокарточки — RocketCraft, владелец формата кадра — протокол,
владелец цели обучения — ИИ. Порядок запуска и проверки — в
[запуске и проверке](/potok-m/docs/project/run/).

Собственный код — `GPL-3.0-or-later`, коммерческая лицензия — отдельным
договором; подробности — в [лицензии](/potok-m/docs/project/licenses/).
