## Watchguard

`potok_ai.watchguard.guard(command, confidence, state, config)` — тотальная
чистая функция: без часов, глобального состояния и мутаций аргументов. Состояние
`GuardState(misses, latched, last_command)` переносится между тиками; `reset()`
— единственный способ снять защёлку.

Проверки идут в фиксированном порядке, поэтому причина отказа однозначна:

`latched → non_finite → out_of_bounds → low_confidence → rate_limit`

Отклонение всегда даёт нулевую команду и оставляет `last_command` на последнем
принятом значении — отброшенный выброс не сдвигает опорную точку проверки
скорости. Пороги включительные; первый отсчёт не проверяется по скорости. Три
последовательных пропуска защёлкивают ассистента, корректный следующий кадр
защёлку не снимает.

Независимое вето на уровне dispatch: `ai_healthy = 0` или невалидные датчики
обнуляют команду, даже если guard её принял. На прошивке те же проверки
зеркалируются в `WatchdogPolicy` и интерлоках; SIL-гейты прогоняют реальный
`step()` с испорченными CRC, seq, паузами и нездоровыми ответами.

## Калибровка confidence

| Метод | Преобразование | Порог |
| --- | --- | --- |
| Temperature | `sigmoid(z / T)` | из отчёта калибровки |
| Isotonic | ступенчатая карта по `p = sigmoid(z)` | из отчёта калибровки |
| Split-conformal | та же карта или точный индикатор `s <= q_hat` | `1/(1+q_hat)` |

Отчёт калибровки детерминирован по байтам и несёт `model`, `seed` и
`config_hash`. Экспорт conformal содержит `alpha`, `tol`, `q_hat`, `n`,
`coverage`, `half_width` и при `with_bin_map=True` — две строго возрастающие
границы. Покрытие считается на независимой выборке: в гейте при
`alpha = 0,05, 0,1, 0,2` оно попадает в `1−alpha ±0,01`. Подмена поля
`coverage` не влияет на результат — он пересчитывается.

Граница `p == p_hat` обрабатывается включительно в обоих маршрутах: при
`side="right"` в bin-map и через `s <= q_hat` в точном маршруте. Любая
повреждённая конфигурация (неизвестный метод, NaN, отрицательный `q_hat`,
немонотонная карта, дубликаты ключей) отвергается громко; отката к
сырой сигмоиде нет.

## Dispatch на edge

`V3Dispatch` гоняет студента на каждом корректном цикле. При низкой confidence
или невалидных датчиках, а также по принудительному расписанию вызывается
учитель — **один вызов на цикл**, даже если оба условия сработали вместе.
Расхождение между головами вызывает `student.reset()`, выбранная команда
проходит через guard. Счётчики `V3Counters` показывают все причины отказов и
количество вызовов teachers; кадр неверной ширины или с нефинитным значением
минует обе модели.

Значения по умолчанию (`frame_len=8`, `confidence_threshold=0,7`,
`forced_check_every=20`, `divergence_factor=3,0`, example bounds ±20 м/с²) —
конфигурация dispatch, а не сертифицированная лётная граница. Порог из
калибровки в production-путь пока не подан: ридер `Calibration` существует, но
вызов `apply_logit` в цикле отсутствует.
