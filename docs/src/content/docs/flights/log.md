## Что фиксируется

- Идентификатор сборки: commit, config hash, версия прошивки и модели.
- Условия: масса, центровка, двигатели, ветер, состояние датчиков.
- Фактические события: ignition, burnout, apogee, deployment, ground hit —
  по тем же именам, что использует симулятор и интерфейс RocketCraft.
- Результат разбора: расхождения с симулятором, сработавшие и не сработавшие
  подсистемы, изменения в Issues.

## Правило сравнения

Числа из симулятора и из лета нельзя смешивать без указания конфигурации и
окна измерения. Даже положительный v3 closed-loop A/B в симуляторе не делает модель
лётно-квалифицированной: до реальных пусков она остаётся наблюдателем.
Подробности — в [гейтах ИИ](/potok-m/docs/ai/gates/).
