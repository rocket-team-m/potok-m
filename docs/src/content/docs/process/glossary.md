---
title: Глоссарий
description: Термины Potok-M и RocketCraft в одном месте.
---

Термин имеет одно значение во всех документах. Если код использует другое
имя, описано именно значение, принятое в проекте.

| Термин | Значение |
| --- | --- |
| Активный участок | часть полёта, на которой работает двигатель; команда ИИ там запрещена |
| Воздушные рули | аэродинамические поверхности ориентации, управляемые сервами |
| Интерлок | независимая аппаратно-программная блокировка, способная veto команду |
| Борт | электроника и авионика ракеты: STM32, датчики, сервы, пиросредства |
| Спасение | система раскрытия парашютов на классической логике таймеров |
| Поиск | радиомаяк и процедура поиска после посадки |
| Watchguard | чистая детерминированная функция фильтрации команды и confidence; отказ — нулевая команда |
| Защёлка (latch) | липкое состояние watchguard после трёх последовательных пропусков; снимается только `reset()` |
| Dispatch | выбор между студентом и учителем на edge; не путать с фильтрацией команды |
| `g_accel` | авторитетная цель v3: запрос бокового ускорения `[g_accel_y, −g_accel_x]`, м/с² |
| `g_theta` | угловая диагностика `[g_roll, g_pitch]`, рад; в команду не повышается |
| `validation.bin` v3 | шесть целей на кадр: четыре legacy-колонки плюс `g_accel_y`/`g_accel_x` |
| `POTOKTRJ` | sidecar истинной траектории; v3 имеет stride 26 и несёт `g_accel` в слотах 24–25 |
| Truth sidecar | привилегированное истинное состояние, ветер и порыв; на борт не едет |
| Held-out | сценарии 16–19, не участвовавшие в обучении; split идёт по сценарию |
| Manifest | версия схемы, config hash, seed, split, границы и SHA-256 всех файлов набора |
| ECE | expected calibration error; низкий ECE на scoring-наборе не доказывает калибровку вне его |
| Split-conformal | калибровка с порогом из порядка статистики `q_hat`; порог `1/(1+q_hat)` |
| JEPA | self-supervised цель: предсказание латентного состояния будущих кадров от EMA-учителя |
| MTP | multi-token prediction: предсказание нескольких будущих горизонтов, здесь K=3 |
| LRS-TCN / RMS-TCN | бортовой студент `StatefulTCN` с причинной depthwise-дилятацией и RMSNorm |
| LoopWM | привилегированный офлайн-учитель с weight-shared LoopBlock |
| LoopWM-lite | спекулятивный верификатор на борту с адаптивным выходом |
| TSCT | низкоранговая спектральная параметризация `U diag(s) Vᵀ` с полярной ретракцией |
| Muon+ | оптимизатор для 2D-проекций с полярной нормализацией; AdamW — для прочих групп |
| Аэрокарточка | таблица коэффициентов на сетке (M, α), которую симулятор потребляет от RocketCraft |
| OpenRocket parity | сверка скалярных величин с фикстурой Simulation 9; регрессионный гейт, не доказательство точности |
| 6-DoF | шесть степеней свободы твёрдого тела с переменной массой |
| Allan variance | источник шумов и смещений датчиков, а не паспортные числа |
| Dryden | корреляционная модель турбулентности; в симуляторе — seeded AR(1)-фильтры |
| Порыв 1-cos | дискретный порыв с огибающей `0,5·A·(1−cos 2πu)` |
| Сдвиговый слой | скачок скорости ветра по высоте в виде центрированного `tanh` |
| SIL | software-in-the-loop: детерминированная проверка реальной логики на хосте |
| HIL | работа с реальной платой; единственная финальная проверка перед лётной квалификацией |
| `no_std` | сборка без стандартной библиотеки для `thumbv7em-none-eabihf` |
| CRC-16/CCITT-FALSE | полином `0x1021`, init `0xFFFF`; контрольная строка «123456789» → `0x29B1` |
| Seq | номер кадра; дубликаты отвергаются, окно перехода по умолчанию 64 |
| Lowlat | облегчённый профиль кадра: запрос 42 Б, ответ 16 Б |
| DAG | ориентированный граф проекта RocketCraft; узел имеет версию, config hash и статус |
| Config hash | детерминированный хеш конфигурации; изменение любого поля меняет его |
| Capability | версионированная возможность C01–C24; без зелёного гейта не считается реализованной |
| Golden | зафиксированный эталон с указанием config hash и coverage |
| Checked / verified | `checked` — посчитано для вашей геометрии; `verified` — совпало с именованным golden |
| Детерминированный режим | выключенные анимации и переходы для съёмки скриншотов |
| Expert ladder | уровни детализации интерфейса: Outcome, Familiar, Project, Expert |
| Static margin | `(CP − CG) / caliber`; калибр — наружный диаметр корпуса |
| Mach | скорость относительно локальной скорости звука |
| Safety factor | во сколько раз прочность детали превышает расчётную нагрузку |
| Pareto | множество проектов, где улучшение одной цели ухудшает другую |
| RANS k-ω SST | модель турбулентности для пограничного слоя; исследовательский режим до прохождения гейта |
