Раздел в работе.

## Правила

- Одна задача — одна ветка, в `main` только через pull request.
- Задача живёт в Issues; без ответственного и срока она не считается задачей.
- Коммиты короткие и по делу: `docs: ...`, `ai: ...`, `hardware: ...`.
- Ревью — один человек, кроме автора. Мелкие правки документации можно мержить
  сразу.
- Секреты и личные данные в репозиторий не попадают.
