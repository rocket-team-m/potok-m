RocketCraft — приватный репозиторий `potok-m-workbench`: десктопная среда
сквозной разработки ракеты — CAD → сетка → проверка → оптимизация → симуляция →
A/B → отчёт. Заявленное покрытие объектов разработки не означает полной
функциональной эквивалентности OpenRocket, SolidWorks или Ansys; оно
фиксируется версионированным списком C01–C24 и честным перечнем
неподдерживаемого.

## Принципы

- Один проект — один DAG. Узел хранит версию, config hash и статус
  `not_run`, `stale`, `running`, `pass`, `fail`, `unknown`. Изменение входа
  помечает зависимые узлы `stale`.
- Никаких silent fallback: частичный импорт показывает loss report, а
  неподтверждённый результат солвера блокирует отчёт.
- Ораклы работают только в dev/CI; в поставку входят golden-фикстуры.
- Солверы называются RocketCraft Solver; код Ansys внутрь не входит.
- Возможность без зелёного гейта не считается реализованной.

`rocketcraft-core` — единственный владелец графа. Доменные crates — листья и
не зависят друг от друга.

| Crate | Вход | Выход |
| --- | --- | --- |
| `rocketcraft-core` | файлы проекта | DAG, артефакты, config hash |
| `rocketcraft-cad` | feature tree | B-rep, массовые характеристики |
| `rocketcraft-mesh` | B-rep | тетраэдральная сетка и метрики качества |
| `rocketcraft-solver-aero` | сетка + конфиг потока | поля и `C_D`, `C_m`, `C_mδ` |
| `rocketcraft-solver-fea` | сетка + карта материала | напряжения и перемещения |
| `rocketcraft-topology` | результаты FEA | поле плотности → ревизия CAD |
| `rocketcraft-io` | форматы файлов | артефакты |
| `rocketcraft-ui` | команды core | GPUI-представления, без физики |

Цикл CFD → FEA → topology → CAD — не цикл зависимостей, а ревизионный узел
DAG с ограничением итераций (по умолчанию 3) и одобрением человека.

## Возможности C01–C24

есть, внешний гейт не пройден; **под гейтом** — исследовательская возможность,

## Гейты возможностей

CAD проверяется на именованном корпусе деталей с допуском 1e-6 rel по объёму,
площади, центру масс и bbox. Для RANS k-ω SST требуется `y+ < 1`, три сетки с
GCI < 5 % и benchmark по пластине или отрывному течению. FEA сверяется с
аналитической консолью и картой материала; SIMP — с ограничениями по массе,
напряжениям и минимальной толщине. Аэрокарточка сверяется с oracle-фикстурами
без заполнения пропусков нулями. Мост к симулятору использует parity-гейт
`potok-sim`; AI/A-B требует положительного контроля oracle на удержанных
сценариях. Несходящийся солвер fail closed и печатает причину.

## Демо

```sh
cargo run -p rocketcraft-ui --features app -- --demo
```

Открывается детерминированный проект `Sample Rocket` без выбора файла: один
параметр подсвечен, чтобы первое изменение дало результат в короткое время.
Управление интерфейсом — в [интерфейсе](/potok-m/docs/rocketcraft/ui/).

## Ограничения

C12–C21 и C23–C24 запланированы; C14 и C16 остаются экспериментальными до
прохождения внешних гейтов. Установщики описаны в спецификации, но пока не
произведены; визуальная матрица не собрана. Внешние ораклы,
лицензированные Fluent-фикстуры и модельные бинарники других репозиториев в
поставку не входят.
