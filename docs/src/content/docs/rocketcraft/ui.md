## Рабочее место

Это не мастер из форм, а постоянное рабочее место: тонкая верхняя полоса с
индексами в квадратных скобках (`[01] ПРОЕКТ`), дерево модели слева, рабочая
область с viewport и панелью проверок в центре, инспектор справа — свёрнут до
выбора элемента.

| Действие | Управление |
| --- | --- |
| Палитра команд | `Ctrl+K`; префиксы `*` проекты, `@` участники, `#` сцены/слои, `!` задания; `↑/↓`, `Enter`, `Esc` |
| Тема | `Ctrl+T` или `Preferences: Color Theme`; стартовая тема — `ROCKETCRAFT_THEME=light|dark` |
| Инспектор | `Ctrl+I` |
| Solving | `F5` или `Solve` в палитре |
| Вид | `F` — вписать, колесо — масштаб к курсору, перетаскивание пустого места — орбита |
| Правки | `Ctrl+Z` / `Ctrl+Y` отмена/повтор, `Ctrl+S` сохранение |

Статус всегда продублирован словом — `OK`, `WARN`, `FAIL`, `UNKNOWN`,
`NOT RUN` — цвет не является единственным носителем смысла. Знак `?` даёт
короткое определение термина; полный словарь — в `FAQ.md` воркбенча.

## Визуальный язык

Палитра собрана из токенов: тёмная тема — фон `#0c0c0c`, поверхность
`#161616`, текст `#f5f5f5`, акцент `#6b8fff`; светлая — фон `#fbfbfb`,
поверхность `#ffffff`, текст `#111111`, акцент `#3457d5`. Обе темы
проверены `theme_tests.rs`. Линии — волосяные 1 px, радиус нулевой, карточек
нет. Моно-индексы в квадратных скобках, отрицательные числа через U+2212.
Отсутствуют эмодзи и декоративная анимация; долгие задачи показывают этап,
шаг, процент, оценку остатка и `Cancel`, а не неопределённый индикатор.

Шрифты заданы семействами Inter и JetBrains Mono (OFL-1.1). Бинарники шрифтов
из репозитория удалены, чтобы пройти лицензионный гейт «без бинарников»: GPUI
запрашивает семейства по имени и использует системный стек. На машине без
установленных OFL-шрифтов кириллица может отобразиться заменяющими символами;
лицензии хранятся в `crates/ui/fonts/NOTICE.md`.

## Глубина интерфейса

Уровни включаются по кнопке и обратимы: `Outcome` — вердикт словами;
`Familiar` — дерево и контекстный инспектор; `Project` — config hash, seed,
версия геометрии, статусы узлов, отчёты импорта; `Expert` — остатки, GCI, `y+`,
коэффициент запаса, Pareto с ошибками, JEPA-диагностика. Переход уровня не
меняет ограничения и config hash.

Пустая панель отвечает на четыре вопроса: что здесь должно быть, почему пусто,
что делать и где узнать больше. Ошибка состоит из трёх частей: что произошло,
почему и что делать; файл или значение называются явно. Несходящийся солвер,
конфликт ограничений, частичный импорт и отказ сохранить — все четыре случая
имеют фиксированный шаблон. Слово `checked` означает «посчитано для вашей
геометрии»; `verified` зарезервировано для совпадения с именованным golden при
указанном config hash и в пределах его coverage.

## Визуальный статус

Визуальная ссылка — редакционная типографика: near-black/near-white,
моно-индексы, тонкие линии, нулевой радиус, без карточек и без эмодзи. Текущее
состояние честно фиксируется в `docs/VISUAL_STATUS.md`:

- токены светлой и тёмной тем корректны;
- скриншотов нет: 0 из 12 ячеек матрицы (2 темы × 2 разрешения × 3 состояния);
  `scripts/check_visual.sh` завершается с 12 ошибками;
- утверждённого baseline нет; детерминированный режим съёмки
  (`ROCKETCRAFT_DETERMINISTIC`, OS Reduce Motion) не подключён;
- из 11 визуальных замечаний устранены 4: ввод в палитре, каскад футера,
  заголовок закрытого инспектора, сдержанность акцента. Остальные — частичные
  или открытые: шрифты, системная тема, type scale, focus ring, верхняя полоса,
  пустые состояния, `tabular-nums`, capture-путь и расхождение палитры между
  кодом и фикстурой.

`Ctrl+T` не сохраняется между запусками, системная тема опрашивается один раз
при старте. Возврат шрифтов и точка съёмки — отдельные задачи; пока
визуальный гейт красный по замыслу, а не из-за временного сбоя.

Источник: `README.md`, `VISUAL_STATUS.md`, `VISUAL_AUDIT.md`, `ONBOARDING.md`,
`FAQ.md` репозитория `potok-m-workbench`, `FIX-WB.md`.
