## Что это за репозиторий

Этот репозиторий хранит документацию, ADR и общие артефакты. Код живёт в
канонических репозиториях `potok-m-ai`, `potok-m-sim`, `potok-m-protocol`,
`potok-m-firmware`, `potok-m-edge`, `potok-m-3d`, а также в приватном
`potok-m-workbench` (RocketCraft). Тяжёлые файлы — CAD, логи полётов,
результаты Ansys — в git не попадают, для них есть Releases.

- **Сайт:** эта документация, собирается автоматически при каждом пуше в `main`.
- **Код:** в канонических репозиториях; здесь остаются только документы и
  лёгкие артефакты.
- **Задачи:** Issues, доска — GitHub Projects.

:::caution
Инженерный прототип. Нет записанных полётов, плата не вводилась в строй,
симулятор не является цифровым двойником, ИИ не допущен к управлению.
Ни один из гейтов не заменяет лётную квалификацию.
:::

Начните с [архитектуры](/potok-m/docs/project/architecture/) и
[запуска и проверки](/potok-m/docs/project/run/).
