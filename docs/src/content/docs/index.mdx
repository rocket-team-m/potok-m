## Что это за репозиторий

Один репозиторий на весь проект: документация, код и артефакты. Тяжёлые файлы
(CAD, логи полётов, результаты Ansys) в git не попадают, для них есть Releases.

- **Сайт:** эта документация, собирается автоматически при каждом пуше в `main`.
- **Код:** `ai/` — модель и симулятор, `hardware/` — электроника и прошивка,
  `vehicle/` — чертежи и аэродинамика.
- **Задачи:** Issues в этом же репозитории, доска — GitHub Projects.
