## Контуры

- **Классический контур.** STM32 собирает датчики, фильтрует их, считает ПИД,
  крутит сервы и держит интерлоки. Спасение, разделение ступеней и таймеры
  не зависят от вычислителя.
- **ИИ-контур.** Raspberry Pi получает окно телеметрии по UART на 50 Гц и
  возвращает две ограниченные поправки с confidence. Контроллер применяет их
  только при открытой фазе и исправном канале; на активном участке вывод
  запрещён.
- **Контур спасения.** Пиросредства идут mimo таймерам и аппаратным признакам;
  ИИ не может ни сработать, ни заблокировать их.

Шесть MEMS дают один вектор методом наименьших квадратов; подробности — в
[концепте ИИ](/potok-m/docs/ai/concept/). Интерфейсы и SIL — в
[встраиваемых системах](/potok-m/docs/protocol/embedded/).
