Список — рабочий черновик. Он описывает предполагаемые роли, а не
утверждённый BOM: питание не выбрано, спорные позиции требуют сравнения, а
физические пины и DMA-каналы определяются только после сверки со схемой.

| Узел | Компонент | Замечание |
| --- | --- | --- |
| Микроконтроллер | STM32H743 | контур управления 500 Гц |
| IMU | ICM42688 | основной датчик |
| IMU (вторичный) | LSM6DSR | резерв |
| Высокоинтенсивный акселерометр | H3LIS331DL | для перегрузок на активном участке |
| Барометр | LPS22HH | сравнить с MS5611 |
| Магнитометр | LIS2MDL | сравнить с альтернативами |
| Flash | W25Q512 | вместо W25Q128 |
| Радио | LoRa1262F30 | модуль, не отдельный SX1262 |
| Питание | не выбрано | номиналы и тестовые точки — из схемы и BOM |

## Что осталось закрыть

- Итоговый BOM с ценами, массами и ссылками на поставщиков.
- Обоснование выбора по каждому спорному компоненту.
- Таблица pin map: USART TX/RX и оба DMA-слота, time driver, IWDG, серво PWM
  тангажа и рыскания, `MOTOR_ARMED`, фазовые события, шины датчиков,
  пиросредства, жужжалка и поисковый радиомаяк. Все физические ячейки в
  HIL-чеклисте намеренно пусты.
- Проверка питаний: короткие замыкания и обратная подача, токоограниченный
  источник, пульсации и просадки под нагрузкой, последовательность включения,
  brownout и холодная прошивка.
