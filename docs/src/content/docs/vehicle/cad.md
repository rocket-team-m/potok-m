Раздел в работе.

## Правила

- Исходники SolidWorks — бинарные: diff и merge для них не работают.
- В git храним манифест, спецификацию и лёгкие экспорты (STEP, STL, PDF).
- Тяжёлые сборки выкладываем в Releases по вехам (`cad-v1`, `cad-v2`).
- Master-копия одна; перед правкой файл забирается через Pack and Go.

## Что здесь будет

- Манифест: какой файл главный, кто владелец, когда обновлён.
- Спецификация и массовая сводка.
- Ссылки на релизы с полными сборками.
