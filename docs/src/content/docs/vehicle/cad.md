`potok-m-3d` хранит текстовые входы (`DESIGN_INPUT.md`, `AEROTUBE.md`) и
каталоги `cad/`, `aero/` с `.gitkeep`. Нативные `.SLDPRT`/`.SLDASM` в git не
попадают: они бинарные, для них не работают diff и merge.  master-копия
одна; перед правкой файл забирается процедурой Pack and Go.

## Обмен геометрией

- Канонический формат — STEP AP214/AP203 и бинарный STL в миллиметрах плюс
  массовые характеристики SolidWorks.
- Тяжёлые сборки выкладываются в Releases по вехам (`cad-v1`, `cad-v2`). На
  момент документации релизов нет, поэтому публично доступны только текстовые
  входы.
- STEP — параметрический источник, а не истина: существующую геометрию нужно
  сверять с актуальными ТТХ перед использованием.
- Манифест фиксирует, какой файл главный, кто владелец и когда обновлён.

## Граница с RocketCraft

RocketCraft — приватный воркбенч, который ведёт цепочку CAD → mesh →
CFD/FEA → аэрокарточка → траектория → отчёт. Симулятор потребляет
аэрокарточку, а не CAD-исходники; это граница между мирами геометрии и
динамики. Подробности — в [обзоре RocketCraft](/potok-m/docs/rocketcraft/overview/).
