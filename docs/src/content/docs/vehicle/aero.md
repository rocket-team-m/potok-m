## Инструменты

- OpenRocket — быстрые оценки компоновок и parity-оракул (Simulation 9).
- Ansys Fluent — детальные расчёты обтекания и коэффициентов.
- RocketCraft — настольный воркбенч, производящий аэрокарточку для симулятора.

Граница для `potok-m-sim` — именно аэрокарточка, а не исходные CAD-файлы.
Запрос коэффициента вне сетки `(M, α)` — громкая ошибка `AeroOutOfGrid`; экстраполяция
и заполнение пропусков нулями запрещены.

## Каноническая сверка

Симулятор сравнивается с OpenRocket Simulation 9 (фикстура `or_sim9.csv`,
эпизод 0, seed 1337, `Config::default()`): апогей 3127,363 → 3185,378 м
(1,86 % при лимите 2 %), Vmax 274,278 → 278,251 м/с (1,45 % при 2 %), время до
апогея 26,9 → 27,04 с (0,14 с при 0,25 с), худшая точка по высоте 4,95 % при
лимите 5 %. Закон лобового сопротивления воспроизводит OR с ошибкой 1–2,3 %
при 5 %. Это регрессионные пины с порогами, выбранными после измерения, а не
доказательство физической точности; подробности — в
[валидации симулятора](/potok-m/docs/sim/validation/).

Противоречие по скорости не решено: ТТХ задают M=0,5–0,6 (≈170–200 м/с), OR
даёт 274 м/с при M=0,82, симулятор — 278 м/с. Коэффициенты под число
не подгонялись.

## Правила хранения

- В git: журналы расчётов, настройки, сетки текстом, скрипты обработки.
- Вне git: `.cas`/`.dat` и тяжёлые результаты; в репозитории — карточка с
  версией, моделью турбулентности, граничными условиями и ссылкой на артефакт.
- Каждый расчёт воспроизводим по журналу, а не по бинарнику.

Собственный код — `GPL-3.0-or-later`, подробности — в
[лицензии](/potok-m/docs/project/licenses/).
