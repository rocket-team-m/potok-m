## Coverage

| Required property | Hard tests |
|---|---|
| Ratio gate | `test_distill_gate_hard_ratio_ece_and_held_out_untouched` trains the real `distill_student.train_episode` loop for 5 epochs on 3 training scenarios, then replays both train and held-out scenarios through the trained stateful student and compares against a fixed windowed teacher at each window end. Asserts finite, non-zero RMSE on both sides and `rmse_held_out / rmse_train <= 1.25` (SPEC_ENGINE_IDEAL.md §4). |
| ECE gate | Same test feeds held-out confidence logits and max-axis correction errors to `conformal_calibrate(tol=0.1, target_ece=0.05, max_loops=3)` and asserts `n == logits.size`, `0 < coverage < 1`, `raw_ece > 0.05`, `ece <= raw_ece` and `ece <= 0.05` (§5). The non-degenerate coverage assertion stops an all-wrong label vector from passing the ECE gate trivially. |
| Held-out untouched | Held-out frames and targets are snapshotted before the fit and compared array-for-array afterwards. A genuinely different held-out pool is constructed but never passed to the trainer; two runs with the same seed and same train data produce a bit-identical `state_dict` for every parameter, so held-out data cannot have influenced the fit. |
| Deterministic seed | `test_distill_seed_controls_the_student_without_global_rng` reseeds the global torch RNG between two `StudentConfig(seed=7)` constructions (identical parameters) and checks that seed 8 differs. The distillation itself uses local generators (`StudentConfig.seed`, `np.random.default_rng(seed + episode_index)`), no global RNG, no wall clock, no fixture files. |

The teacher is a small deterministic windowed map (`tanh` of the mean of the
last 4 sensor frames, fixed `torch.Generator` seed 2024) whose corrections stay
inside the student's `tanh(g_max)` output bound. A randomly initialised
`PotokModel` saturates that bound and makes the gate measure an unlearnable
target instead of the distillation pipeline.
