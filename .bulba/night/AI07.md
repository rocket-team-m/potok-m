## What the file gates (21 tests)

1. **Coverage at alpha** — parameterized over `alpha = 0.05, 0.1, 0.2`. Fits on
   30 000 held-out Gaussian errors, exports `conformal.json`, and scores a
   **disjoint** 30 000-sample split through the edge route (`conformal_coverage`).
   Asserts coverage ≈ `1-alpha` (±0.01), the finite-sample lower bound
   `>= 1-alpha-0.005`, and equality with the exact `s <= q_hat` indicator.
2. **JSON export/import** — pinned payload key set, deterministic bytes
   (sorted keys, fixed indent, trailing newline), `from_json` equality,
   `as_dict() == json.loads(text)`, no raw calibration scores in the payload,
   and decision preservation through `apply_confidence` and the reloaded fit
   from the trainer's file path.
3. **No in-sample self-certification** — a deterministic fixture where every
   calibration error equals `q_hat`, so in-sample coverage is exactly 1.0 while
   a disjoint 100-sample split scores exactly 0.95. The gate must report the
   disjoint number; a forged `coverage` field (`0.0`, `1.0`, `NaN`) is inert and
   never changes the recomputed result.
4. **Loud corrupt input** — 14 parameterized corrupt payloads (wrong method,
   missing key, bad `alpha`/`tol`/`q_hat`/`n`, one-sided bin map, non-monotone
   edges/values) refused by both `from_dict` and `conformal_coverage`; malformed
   JSON refused by `from_json`; empty/NaN/inf/too-small fit inputs refused by
   `conformal_export`.

## Observation, not fixed (out of scope)

The bin-map route maps `p` through "first upper edge `>= p`", so at the exact
boundary `s == q_hat` it reports *not confident*, while the exact indicator
reports *confident*. The self-certification test therefore exports with
`with_bin_map=False` to keep the boundary unambiguous; the coverage-at-alpha
and round-trip tests exercise the bin map on continuous data where ties do not
occur. This is pre-existing `conformal.py` behaviour and was deliberately not
changed (no source edits permitted).
