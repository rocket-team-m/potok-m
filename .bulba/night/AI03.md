## What was built

Seven pytest functions pinning the calibration/conformal report artifact, all on
synthetic data with fixed seeds (no production `out/` file is read):

1. `test_calibration_report_json_is_byte_deterministic` — two fits of the same
   held-out data give byte-identical JSON; the engine-written `calibration.json`
   (`build_metrics`) is byte-identical across two runs and carries `model`,
   `seed`, `config_hash` matching `config_hash(cfg)`.
2. `test_calibration_report_ece_and_coverage_gates` — `ece <= target_ece`,
   `ece <= raw_ece`, `temperature_ece <= raw_ece`, `coverage == mean(correctness)`,
   threshold in `[0,1]`, `1 <= loops <= 3`; recomputing ECE from the exported
   payload reproduces the reported ECE exactly (isotonic fixture, ECE ~0).
3. `test_temperature_export_report` — temperature payload has no `bins`/`values`,
   round-trips through JSON, and `apply_calibration` reproduces `sigmoid(z/T)`.
4. `test_isotonic_export_report` — `bins`/`values` are monotone and in range;
   step map reproduces `isotonic_calibration(sigmoid(logits), correct)` to 1e-12,
   including the edge reader's `n+1`-edge form.
5. `test_conformal_export_report` — `to_json` is deterministic, `from_json`
   round-trips, `q_hat` equals the analytic order statistic, `half_width == q_hat*tol`;
   `conformal_export` writes `conformal.json` and `conformal_coverage` on a
   disjoint split lands within 0.01 of `1-alpha` and above `1-alpha-0.005`.
6. `test_corrupt_calibration_input_is_loud` — ECE rejects shape/empty/out-of-range;
   `conformal_calibrate` rejects mismatched lengths and `max_loops < 1`;
   `apply_calibration` rejects unknown method and malformed isotonic map.
7. `test_corrupt_conformal_report_is_loud` — `fit_conformal` rejects empty/NaN/inf/
   bad tol/alpha; `ConformalResult.from_dict` rejects wrong method, negative
   `q_hat`, bad alpha, non-increasing edges, missing keys; `conformal_coverage`
   refuses a temperature/isotonic report (different semantics).
