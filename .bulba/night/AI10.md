# Night task AI10 — A/B report hard gate

**Status:** done. Local commit only, nothing pushed. No subagents. No source edits.

## Scope

Created exactly one test file: `ai/tests/test_ab_report_gate_hard.py`
(`SPDX-License-Identifier: GPL-3.0-or-later`, 7 tests). No file under `src/`,
no generator, no report artifact and no CI config was edited. This report is
the only other file written.

The test is self-contained: it builds deterministic synthetic reports shaped
like the shipped `ab_report.json` schema and gates them in memory. Nothing under
`out/`, no GPU and no simulator is read; no model quality or flight claim is
made.

## What the file pins

1. **Schema** — required top-level fields and types, decimal seed keys, every
   declared student present under every seed, `aggregate.baseline`/`assisted`
   arms with finite positive `lateral_rms_m`/`apogee_m`, typed `seed_order`,
   `held_out_indices`, `students`, `verdict` and `exit_code`. Twelve mutations
   (missing keys, wrong types, NaN/negative metrics, bad seed key) are refused.
2. **Oracle positive control** — every seed must carry `oracle_gtheta` and it
   must lower lateral RMS and raise apogee against its own baseline; a missing,
   equal-sign or non-finite oracle is rejected. Without this, a report cannot
   show the instrument detects an improvement at all.
3. **Held-out seed provenance** — held-out indices must be non-empty, unique and
   map to withheld scenario cells (`index % 20 in {16,17,18,19}`); seed keys must
   match `seed_order`; each arm must carry per-scenario rows whose `scenario`
   labels are declared held-out cells and a 64-hex SHA-256 for both arms.
4. **No surrogate claims** — `measurement` must name the flown-truth trajectory
   sidecar and explicitly say "not surrogate"; `supersedes` must void the
   earlier surrogate A/B; `sim_source` must credit the physical oracle command;
   `task`/`seed_note` may not contain a surrogate claim.
5. **Exit-code contract** — `exit_code`, `verdict.pass`, `beats_lateral` and
   `beats_apogee` are recomputed from the arms (a pass additionally requires a
   working oracle); a failing report must carry a failure location. The CLI is
   runnable as a script and exits 0 on pass, 1 on any gate violation, 2 on a
   malformed file or bad invocation — asserted both in-process and via
   `subprocess`.

The gate is also checked against the real historical artifact (`ab_report.json`
at commit `593d7ac`, read only from git into `/tmp`): `_check()` returns zero
errors on it. It is a valid *failing* report (exit_code 1, students lose, oracle
wins), so the gate does not encode a "students win" assumption.
