## Что добавлено

Новая секция **«5. Прогноз точки посадки (без GPS)»** с подсекциями:

- **5.1 Входные данные** — таблица происхождения каждого входа. Точка старта —
  OPERATOR INPUT; ветер (`w_10 = 2.0 м/с`, `kappa = 0.22`, `shear_delta = 0`,
  `gust_probability = 0`) — TTX-значения из `sim/config/default.toml` `[wind]`;
  скорости снижения drogue 25 м/с / main 6.5 м/с, триггеры `apogee + 2.0 s` и
  1500 м, времена надувания 1.2 / 2.0 с и `wind_coupling_s = 3.0` — плейсхолдеры
  `[parachute]` из того же файла (`enabled = false`). Погрешности (`sigma_W`,
  `sigma_phi`, `sigma_v/v`, `sigma_z`, `sigma_t`, `sigma_launch`) явно помечены как
  OPERATOR INPUT / PLACEHOLDER. Нет входа — прогноз даёт `UNKNOWN`, а не ноль.
- **5.2 Модель** — локальная плоскость ENU, кусочно-линейное снижение
  `z(t) = z_deploy - v_desc·t`, `T_stage = (z_deploy - z_next)/v_desc`, степенной
  профиль ветра `w(h) = w_10·(h/10)^kappa` и интеграл по высоте
  `|dR| = w_10/(10^kappa·v_desc·(kappa+1))·(z_deploy^(kappa+1) - z_next^(kappa+1))`.
  Проверены размерность и предельный случай `kappa = 0`. Отдельным членом идёт
  консервативный снос до/при раскрытии `W(z_apogee)·(t_delay + tau_d + tau_w)`.
- **5.3 Эллипс** — дисперсии вдоль и поперёк ветра: скорость ветра, ошибка
  скорости снижения (`R_i·sigma_v/v_i`), ошибка высоты раскрытия main, ошибка
  времени раскрытия drogue, ошибка ввода точки старта и ошибка азимута.
  Ковариация `C = sigma_along²·u·uᵀ + sigma_cross²·n·nᵀ`; 1σ-полуоси и 95 %
  при `k = 2.45` из `P(r ≤ kσ) = 1 - exp(-k²/2)`.
- **5.4 Обновление по телеметрии** — таблица: `phase = APOGEE`/EVT апогея фиксирует
  `z_apogee`; `TLM.height_dm` (0.1 м/ед.) с флагом `BARO` задаёт текущую `z` и остаток
  снижения; EVT deployment убирает неопределённость времени; пересечение 1500 м
  переключает `v_d → v_m`; повторный наземный зондинг пересчитывает весь интеграл.
  Кадро нет — поле `NOT RUN`/`UNKNOWN`, а не старое значение. Только приём, никаких
  `CMD` в полёте (§3.6).
- **5.5 Связь с `[03] SEARCH 144`** — `DRIFT ESTIMATE` и `SEARCH AREA` получают
  расчётный снос и оси эллипса; пеленг ±15° даёт сектор, область поиска —
  пересечение сектора с эллипсом; RSSI до калибровки остаётся `NOT MEASURED` и не
  превращается в дальность или GPS-подобную точку.
- **5.6 Один пример счисления** с реальными единицами: `T_d = 20.0 с`,
  `T_m = 230.8 с`, снос drogue 124 м, main 1139 м, задержка 40 м, итого 1304 м
  на 070°; восток 1225 м, север 446 м; на 55° с.ш. это `+0.00401°` широты и
  `+0.01921°` долготы, точка 55.00401° N, 37.01921° E; 1σ = 173 × 114 м,
  95 % = 423 × 280 м. Статус `CALCULATED / NOT A FIX`.
